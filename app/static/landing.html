Hybrid Token Filter — regex + local LLM

A PreToolUse hook that intercepts CLI commands and rewrites them with output truncation before execution.

Command Classification

98%
command coverage (vs 46% regex-only)

Regex handles 19 known commands instantly. MLX classifies 21 more — kubectl, terraform, brew, pip, compound && chains — at ~370ms overhead.

Output Summarization

98%
token savings on large outputs

Very verbose outputs (git diff, build logs, JSON APIs) are piped through a local MLX summarizer that extracts errors, warnings, and key data. Head truncation achieves 27% — MLX achieves 98%.

Why PreToolUse?

Filtering at the proxy level breaks Anthropic's prompt caching — cache keys are exact-match. A cache miss on Sonnet costs 10x ($3 vs $0.30 per 1M tokens). The PreToolUse hook rewrites the command before it runs, so the truncated output is what enters the conversation. Caching works normally.

Zero Cloud Dependency

The MLX model runs locally on your Mac via Apple's MLX framework. No API calls, no data leaving your machine, no per-token cost. Recommended model: Qwen2.5-7B-Instruct-4bit or gemma-4-e2b-it for speed.

Bash command → PreToolUse Hook ├─ Layer 1: Regex (<1ms) — git, find, grep, cat, pytest, docker, ls, ps ├─ Layer 2: MLX classify (~370ms) — SKIP | HEAD | TAIL | SUMMARIZE └─ Layer 3: MLX summarize (~5-22s) — intelligent extraction for very large output Fallback: MLX server down → regex-only mode (no error, no hang)
Requires Apple Silicon Mac (M1/M2/M3/M4) — MLX framework runs on Apple GPU only. Other platforms coming soon.

Get running in seconds

Point your Anthropic SDK at the proxy — that's it.

# 1. Start the proxy
uvicorn app.main:app --host 0.0.0.0 --port 4000

# 2. Issue a virtual key from the admin dashboard (/ui/admin)
#    then point the Anthropic SDK at the proxy
export ANTHROPIC_BASE_URL="http://localhost:4000"
export ANTHROPIC_API_KEY="ccm_your_issued_key"

python -c "import anthropic; print(anthropic.Anthropic().messages.create(
  model='claude-sonnet-4-6',
  max_tokens=64,
  messages=[{'role':'user','content':'hi'}]))"
